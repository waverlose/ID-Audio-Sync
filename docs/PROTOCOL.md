# 通信协议说明

ID Audio Sync 只有两条网络路径，全部走局域网，不需要任何服务器。

```
 发送方 (这台出声)                              接收方 (这台听声)
 ┌──────────────┐                              ┌──────────────┐
 │ WASAPI       │                              │              │
 │ loopback 抓取 │ ── ① UDP 广播配对 ─────────► │ Discovery    │
 │ 系统声音      │ ◄─ 应答 IP/端口 ──────────── │ Responder    │
 │              │                              │              │
 │ PCM 分帧      │ ── ② TCP 音频流 ───────────► │ 抖动缓冲      │
 │              │    48kHz/2ch/int16           │ 播放到扬声器   │
 └──────────────┘                              └──────────────┘
```

---

## ① 自动配对（UDP）

| 项目 | 值 |
| --- | --- |
| 传输层 | UDP |
| 端口 | `31236` |
| 组播组 | `239.255.42.99` |

**探测包（发送方 → 广播）**

```
IDAS2|PROBE|<发送方主机名>
```

广播目标会同时发往：每个网卡对应的定向广播地址、`255.255.255.255`、组播地址 `239.255.42.99`。
定向广播地址不用系统返回的 `dwBCastAddr`（实测常为垃圾值），而是按 `ip | ~mask` 自行计算。

**应答包 / 周期宣告（接收方 → 发送方）**

```
IDAS2|HERE|<接收方主机名>|<音频 TCP 端口>
```

接收方在 `0.0.0.0:31236` 上监听；收到探测立即单播应答，同时每 **3 秒** 主动广播一次自己的身份。
发送方解析出 `(ip, tcp_port, name)` 后直接建立 TCP 连接，并把 `ip` 记进配置的 `peer` 字段，下次开机秒连。

**自身过滤**：发送方会丢弃主机名等于本机、或源 IP 属于本机网卡的应答，避免"自己连自己"造成音频自环。

## ② 音频流（TCP）

| 项目 | 值 |
| --- | --- |
| 传输层 | TCP（`TCP_NODELAY` 开启） |
| 端口 | `31235`（可配） |
| 采样率 | 48000 Hz |
| 声道 | 2（立体声） |
| 采样格式 | 16-bit 有符号整型、小端、交错 |
| 帧长 | 20 ms（960 帧，3840 字节） |

**握手**

```
发送方 → 接收方:   "IDAS1" + <可选共享令牌>
```

接收方校验前缀必须为 `IDAS1`；若配置了 `token`，令牌不匹配则直接断开。

**数据帧**

```
+----------------+--------------------------+
| 4 字节长度(LE)  |  payload（int16 交错 PCM）|
+----------------+--------------------------+
```

- **长度 = 0**：静音心跳。表示"这一帧没声音"，接收方补一段静音，连接保持不断。发送方在 RMS 低于静音门限时只发心跳，空闲带宽降到几十 kbps。
- **长度异常**：若 `长度 > 帧字节数 × 8`，视为协议错乱，立即断开重连。

**抖动缓冲**

接收方用有界队列（48 帧 ≈ 960 ms 上限）做缓冲，播放线程按 20 ms 节奏取帧。
队列满时丢弃最旧的一帧（`dropped++`）；队列空时播静音并记 `underruns++`。
播放侧对增益做约 60 ms 的淡入淡出，切换静音/恢复时不会"啪"一声。

---

## 角色仲裁

`role` 配置为 `auto` 时：

1. 先广播找接收方；
2. **找到了** → 本机当发送方；
3. **没找到** → 本机当接收方，再等一轮；
4. 若第二轮发现另一台也在当接收方，则用**主机名做确定性排序**（名字小的当发送方），保证两边不会同时听或同时发。

---

## 端口与防火墙

首次安装会自动加两条入站放行规则（TCP 31235、UDP 31236）。
若被安全软件拦截，可在"诊断信息"里确认端口，再手动放行。
